### 🔴 `BABEL` — AI Speech Translator
> Real-time speech-to-speech translation across 30+ languages with live subtitles

**Stack:** `Flask` `WebSockets` `Groq LLaMA 3.1` `Faster-Whisper` `gTTS` `Bootstrap`  
**What it does:** Captures microphone audio → transcribes with Whisper → translates via Groq → outputs translated speech + subtitles in real time. Supports conversation mode for two-person multilingual dialogues.

### 🟠 `DOCUMIND` — RAG PDF Chat System
> Upload any PDF and talk to it — summaries, flashcards, quizzes, key terms

**Stack:** `Flask` `Python` `Groq LLM` `Local Embeddings` `Vector Search`  
**What it does:** Full RAG pipeline — PDF extraction → chunking → embedding → vector retrieval → Groq-powered response. Keeps answers grounded in document context, not hallucinated.

### 🟢 `VOCA` — Browser-Based AI Voice Assistant
> Voice-in, voice-out AI assistant with session memory — zero paid speech APIs

**Stack:** `Flask` `Groq (Llama 3)` `Web Speech API` `SpeechSynthesis API` `JavaScript`  
**What it does:** Uses native browser APIs for STT and TTS — no third-party speech costs. Maintains conversation context across the session. Dark/light mode, voice selector, replay.
